# Deploy `devin-orchestrator`

This repository contains a one-click, cross-platform deploy path for the
`devin-orchestrator` MCP server so **all** local agentic tools (Cascade, Hermes,
Claude, Cursor, Aider, Windsurf, OpenClaw, etc.) can use it.

It works on Linux, macOS, and Windows.

## One-click deploy

The same Python script works everywhere.

### Linux / macOS

```bash
./deploy.sh
```

or directly with Python:

```bash
python3 deploy.py
```

### Windows

From PowerShell or CMD in the repo root:

```powershell
py deploy.py
```

or, if you only have `python` in your PATH:

```powershell
python deploy.py
```

This does two things:

1. `install.py` — copies the package, skills, workflows, roles, and config to
   `~/.devin-orchestrator/` (or `%USERPROFILE%\.devin-orchestrator` on Windows),
   creates a launcher, and makes sure the logs directory exists.
2. `register_mcp.py` — adds/updates the `devin-orchestrator` MCP server entry in
   every known local agent config file.

## Dry run

See exactly what would change without touching any files.

### Linux / macOS

```bash
./deploy.sh --dry-run
```

### Windows

```powershell
py deploy.py --dry-run
```

## Manual steps

If you prefer to run the pieces individually:

### Linux / macOS

```bash
python3 install.py           # install package and launcher
python3 register_mcp.py      # register with agents
```

### Windows

```powershell
py install.py
py register_mcp.py
```

`register_mcp.py` supports a few useful flags:

- `--list` — show the status of each agent config.
- `--dry-run` — show what would change without writing files.
- `--remove` — remove the `devin-orchestrator` entry from every config.
- `--global-root <path>` — install to a non-default global root.

## Where the launcher lives

The launcher is a tiny wrapper generated by `install.py`.

- **Linux / macOS:** `~/.local/bin/devin-orchestrator`
- **Windows:** `~/.devin-orchestrator\bin\devin-orchestrator.bat`

On Linux / macOS you may need to add `~/.local/bin` to your PATH if it is not
there already.

On Windows, the launcher lives inside the global root so you do not have to
edit your PATH.  Every agent config points to it directly.

## Agent configs touched by `register_mcp.py`

`register_mcp.py` tries the usual cross-platform locations and picks the one
that already exists (or creates the default fallback).

- **devin:** `~/.config/devin/mcp_config.json` or `%APPDATA%\devin\mcp_config.json`
- **aider:** `~/.aider/mcp.json` (or `%USERPROFILE%\.aider\mcp.json`)
- **windsurf:** `~/.codeium/windsurf/mcp_config.json` or OS-specific appdata
- **pi:** `~/.pi/agent/mcp.json`
- **claude:** `~/.claude.json` or `claude_desktop_config.json` under appdata
- **hermes:** `~/.hermes/config.yaml` or `%APPDATA%\hermes\config.yaml`

## Other useful commands

```bash
python3 deploy.py --version
python3 deploy.py --smoke-only
python3 deploy.py --uninstall --dry-run
python3 deploy.py --keep-backups 5
python3 register_mcp.py --snippet
```

## Notes

- **Python:** `install.py` and `register_mcp.py` require Python 3.10 or newer.
- **PyYAML:** only needed for the Hermes YAML config.  If you do not use Hermes
  you can skip it; otherwise `pip install pyyaml` before registering.
- **Python version on Windows:** `deploy.py` / `install.py` use the interpreter
  that runs them (`py` / `python` / `python3`).  Use `--python` if you want to
  pin a different interpreter in the launcher.

## Troubleshooting

See [TROUBLESHOOTING.md](TROUBLESHOOTING.md) for common install, PATH, PyYAML, stale process, and smoke-test issues.

## After deploying

Most agents read their MCP config on startup.  Restart the agent/IDE (or its MCP
connection) so it spawns the new `devin-orchestrator` process.
